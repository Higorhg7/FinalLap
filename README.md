# FinalLap — responsive landing page

A responsive front-end recreation inspired by the supplied reference screenshot.

## Run locally
1. Unzip the project.
2. Open `index.html` in a browser, or use a local server (recommended):
   - `python -m http.server 8000`
   - Visit `http://localhost:8000`

## Stack
- HTML5, CSS3, vanilla JavaScript
- GSAP + ScrollTrigger (loaded from CDN)
- Google Fonts: Playfair Display and DM Sans

## Notes
- Layout adapts for desktop, tablet, and mobile.
- Includes mobile navigation, working demo signup feedback, and scroll reveal animations.
- Vehicle and portrait photography is loaded from Unsplash URLs, so an internet connection is required for those images and the external fonts/GSAP CDN.
- The form is a front-end demo and does not submit personal information to a backend.
